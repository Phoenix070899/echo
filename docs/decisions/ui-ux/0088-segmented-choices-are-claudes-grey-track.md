# Segmented choices are a grey track with a white thumb, never the system picker

Decided: 2026-11-12
Status: accepted

Chat | Terminal | Changes in a Worker's header, the number of tries in Fan Out, and Light | Dark in Settings use `LedgerSegmented`: a `Ledger.bubble` track, the picked choice on a `Ledger.field` thumb with a hair of shadow, 12 pt text, 24 pt tall.
The system's segmented picker is not used: its thumb is the accent blue of macOS, which no other control in Echo wears.
Why: Claude's own toggle is a grey track with a white thumb, and the blue one was the only part of a Worker's header that did not match.
