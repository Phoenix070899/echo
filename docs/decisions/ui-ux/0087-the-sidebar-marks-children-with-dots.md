# The sidebar marks a row's children with a dot, not a guide line

Decided: 2026-11-12
Status: accepted

Supersedes: ui-ux/0084, only its indent guide lines.
There is no vertical line in the sidebar. A small dot sits at the left of each agent row (under the repo's icon) and each Worker row (under the agent's glyph), where a line would have run.
A Worker that ended badly keeps its red mark but its title reads in the normal grey; red text on every such row made the list shout.
An agent's fold chevron shows while the pointer is over its row, or while it is folded.
The Settings list and the collapsed rail sit flat on the window like the sidebar, not on a card.
Why: the human found the lines noisy and asked for bullets instead.
