# Start a session is a numbered Foundry form on a raised sheet

Decided: 2026-11-14
Status: accepted

The modal is 600 pt wide, the sheet in a 2 pt ink frame casting an 8 pt hard ink block over the window dimmed with ink at 38 %.
Its head is a "NEW SESSION" label, "START A SESSION" in the display face at 34 pt, a line under it, and a 28 pt close square, over a 2 pt ink rule.
The steps are numbered mono labels: 01 / Mode (two cards, the picked one in a 2 pt ink frame casting a 4 pt accent block), 02 / Repo (40 pt rows between 1 pt rules, the picked one sunk with an accent edge and bold), 03 / Create from (a compact segmented choice, a 38 pt field and the base branch), 04 / Name with the Team (or the model) beside it as a field-shaped menu, and the Team's summary on the sunk grey.
The foot sits on a 1 pt rule: where the agent joins on the left, Cancel and Start on the right at 36 pt.
Rename uses the same sheet and head.
Why: the StartSession artboard; the words stay the app's (Orchestrator, Normal, Team).
