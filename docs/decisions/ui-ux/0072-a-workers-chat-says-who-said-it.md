# A Worker's chat puts the Orchestrator's messages on the left, labelled

Decided: 2026-11-12
Status: accepted

In a Worker's chat, a message the Orchestrator typed in (its Task, `worker send`, `worker task`) sits on the left in a wash bubble headed "From Orchestrator".
What the human typed (the message box, a review from Changes, or straight into its terminal) sits on the right, as in any chat.
Echo's own notes read as one dim line: the note a resumed session starts with, and the Task and retry the daemon writes for a verifier and its writer.
Why: a Worker hears from two people, and the terminal never showed which one spoke.
