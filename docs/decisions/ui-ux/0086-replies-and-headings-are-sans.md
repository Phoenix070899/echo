# Replies, headings and the Markdown view are the system sans, not a serif

Decided: 2026-11-12
Status: accepted

Supersedes: ui-ux/0080 and ui-ux/0085, only where they set the agent's replies and the headings in a serif.
Every text in Echo is the system sans (SF); only code, commands and paths stay monospaced. `Ledger.serif` is gone.
A reply is 15 pt sans on a 6 pt line gap, and a Markdown heading is semibold sans, in the chat, the Final Report and the file preview alike.
Why: the human wanted the main content in a sans serif, as Claude Desktop's Code tab sets its transcript.
