# A scrolled-up chat shows Jump to bottom

Decided: 2026-11-16
Status: accepted

When a chat is scrolled more than 200 pt up from its end, a "↓ Jump to bottom" button shows over the messages, centred on the message box's top edge.
It is Foundry's primary button, so it reads over any message; clicking it scrolls to the end, without animation when Reduce Motion is on.
It fades out once the chat is back at its end.
Why: the human could not tell a chat was scrolled up, or get back to the newest message in one step.
