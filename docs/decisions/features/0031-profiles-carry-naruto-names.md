# Every Agent Profile is named for a Naruto character

Decided: 2026-10-27
Status: accepted

Each profile in `profiles/` takes a Naruto character's name that fits its role: naruto implements, sasuke verifies, hinata analyses, jiraiya researches, ino keeps Preferences, lee runs commands.
The command runner was `bash` and is now `lee`: Rock Lee has no ninjutsu and only does the drills he is given, as the runner only runs the commands its Task names and never edits files.
A new profile picks a character in the same way, never a tool or role word.
Why: the human wanted one name theme, and `bash` read as the shell rather than a Worker.
